# 🩺 医路心愿墙 · Medical Wish Wall

医学生专属心愿墙——写下你的医路心愿，让每一份坚持都被看见。

Live: https://dalihaif.github.io/medical-wish-wall/

## 功能

- 💊 **处方笺式发布**：以"心愿处方笺"形式发布心愿，支持 7 大分类（考试 / 考研 / 规培 / 科研 / 英语 / 健康 / 其他）
- 📝 **便签墙展示**：便签随机倾斜、按分类配色、热门心愿置顶
- ❤️ **点赞加油**：医路同行，为别人的心愿点个赞
- 🔍 **分类筛选**：按分类快速查看
- 📊 **实时统计**：心愿总数、累计点赞、最热分类
- 💾 **本地存储**：心愿保存在浏览器 localStorage，刷新不丢失

## 技术

纯 HTML + CSS + 原生 JS，无任何依赖，单页应用。

## 部署

推送 `main` 分支后 GitHub Actions 自动部署到 GitHub Pages。
